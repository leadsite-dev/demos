# demos

Páginas de demonstração do LeadSite, servidas pelo GitHub Pages.

- Cada demonstração fica numa pasta com nome aleatório; não há índice das páginas.
- Todas as páginas têm `noindex` e o repositório tem `robots.txt` bloqueando tudo.
- Publicação e remoção são feitas pelo publicador do LeadSite (ver `docs/DEMOS.md` no repositório principal).
